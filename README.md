## About

I'm a Computer Science graduate from the University of Mumbai with experience building production blockchain systems, full-stack applications, and AI-powered cloud workflows.

Currently focused on **AWS, AI engineering, and cloud-native application development** — building systems that combine serverless computing, managed AI services, document processing, and backend automation.

Recently built a serverless invoice-processing pipeline using **Amazon S3, AWS Lambda, Amazon Textract, Amazon Bedrock, and DynamoDB**, with a Streamlit dashboard for reviewing processed invoices.

My background also includes developing upgradeable DeFi vaults across multiple blockchains, building Web3 applications, and co-authoring a research paper on an on-chain orderbook DEX published in IJRASET.

I enjoy working across the entire stack — from cloud infrastructure and Python-based automation to AI integrations, backend systems, smart contracts, and user-facing applications.

- **AWS & Serverless:** Building event-driven workflows with S3, Lambda, DynamoDB, and managed AWS services.
